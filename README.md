# Toki Bot Backend

Этот сервис присылает два ежедневных напоминания в Telegram. Рабочий групповой чат остаётся в WhatsApp; сервис не читает его и не отправляет в него сообщения. Напоминания можно получать в личном чате с ботом или в отдельной Telegram группе.

## Почему не в существующий WhatsApp чат

Официальный [WhatsApp Groups API](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups.md/) предназначен для новых групп, созданных через API: участники вступают по приглашению, а доступ предоставляется бизнесу с Official Business Account. Он не подключает API бота к обычному существующему групповому чату. Автоматизация через WhatsApp Web и неофициальные библиотеки зависит от веб интерфейса и сессии номера, поэтому не используется здесь.

Для отдельной личной переписки WhatsApp Business Platform возможен официальный Cloud API, но это другая интеграция: нужен бизнес номер, согласие получателя, а инициированные сообщения и сообщения вне 24 часов после ответа пользователя требуют одобренного шаблона. Она не решит задачу отправки именно в текущий групповой чат.

## Настройка

Требуется Python 3.10+ и один постоянно работающий процесс приложения.

```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

Создайте Telegram бота через BotFather, начните с ним личный диалог (или добавьте его в отдельную Telegram группу) и узнайте `chat_id` этого диалога. Задайте переменные окружения на сервере; реальные значения не добавляйте в Git:

| Переменная | Назначение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен Telegram бота |
| `TELEGRAM_CHAT_ID` | ID личного чата или отдельной группы для напоминаний |
| `REMINDERS_ENABLED` | `true` включает расписание; по умолчанию `false` |
| `REMINDER_TIMEZONE` | Часовой пояс IANA, по умолчанию `Europe/Istanbul` |
| `STOCK_REMINDER_TIME` | Время сверки остатков, по умолчанию `18:30` |
| `CASH_REMINDER_TIME` | Время отчёта по кассе, по умолчанию `19:00` |
| `STOCK_REMINDER_TEXT`, `CASH_REMINDER_TEXT` | Необязательные тексты напоминаний |
| `REMINDER_API_KEY` | Секрет для ручной проверки отправки; без него ручная отправка отключена |

Время задаётся как `HH:MM` в 24 часовом формате. Неправильное время или отсутствующие Telegram настройки при включённом расписании останавливают запуск. Расписание живёт в памяти: приложение должно работать в нужный момент; после простоя пропущенные напоминания не воспроизводятся. Запускайте ровно один worker и одну реплику, иначе сообщения продублируются. Не используйте `--reload` для работающего расписания.

## Проверка отправки

Для ручного теста задайте `REMINDER_API_KEY` и вызовите:

```bash
curl -X POST https://YOUR-SERVICE/send-telegram \
  -H "X-API-Key: YOUR_REMINDER_API_KEY"
```

Прежний публичный `GET /send-telegram` заменён защищённым `POST`: открытая ссылка позволяла любому посетителю отправлять сообщения от имени бота. Ответ `{"status":"sent"}` означает, что Telegram принял запрос; проверьте доставку в целевом чате. На Render используйте Web Service с постоянно работающим экземпляром и Start Command `uvicorn main:app --host 0.0.0.0 --port ${PORT:-8000}`. Если инстанс засыпает, напоминания в это время не отправляются.
